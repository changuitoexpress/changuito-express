## 📏 RESPETO A VARIABLES CSS GLOBALES

El código actual usa `var(--bg-card)`, `var(--text-primary)`, etc.

**MANTÉN esa lógica de temas** pero SOBRESCRIBE con colores específicos:

```tsx
const isDark = props.theme === 'dark';

// En estilos:
background: isDark ? '#1F2937' : '#FFFFFF',
color: isDark ? '#F3F4F6' : '#000000',
// Pero siempre usa #F59E0B para botones, independiente del tema
```
